Where is the main window?

Startup begins in the menu bar. Click its item, then Open showmac. Closing the main window keeps monitoring running. Right-click the menu bar item for actions; use Quit ShowMac to exit fully.

Choose the right download

Apple M-series Macs use ARM64; Intel Macs use the Intel download. Replace the existing app in Applications instead of running both copies. The current full desktop preview is ad-hoc signed and not notarized, so macOS may report that its developer cannot be verified. A notarized public release is not yet available.

Apple Silicon

  1. Download the ARM64 ZIP from the download section, then double-click it to extract showmac.app.
  2. Quit the existing ThermalScope or ShowMac app, move showmac.app to Applications, then open it. Your existing desktop-edition preferences use the same app identity.

Intel

  1. Download the Intel ZIP, then double-click it to extract showmac.app.
  2. Quit the existing app, move showmac.app to Applications, then open it. Do not run two fan controllers at once.

Missing readings are not zero

Sensors differ across Mac models. Use Sensors → All sensors to see what this Mac exposes. Unsupported readings remain unavailable. Recent history starts with the current session and clears on quit.

Adjust fan behavior

In the full desktop edition, choose a preset under Thermal control or drag a curve point and release to apply. Select Auto to return control to macOS. Control keeps running by default. Set timer… adds a one-shot auto-off timer; monitoring continues afterwards. Quit other fan controllers before applying control. Apple Silicon support is experimental and depends on the model.

Electricity usage and cost

Open Usage statistics in the sidebar, the compact Live metrics card or the menu bar More menu. Choose the Electricity or Token tab; each keeps its own date selection. Energy, estimated cost and average power are shown together. Browse Day, Week, Month and Year. The power curve supports an hourly view and inspection of original sample time/wattage. Set your own price per kWh and currency; no rate is assumed. Device power, DC input and battery discharge stay separate. Only continuously sampled intervals while ShowMac runs are counted. Sleep, exit and missing readings are excluded. Local history survives relaunch. Power detail retains original first/min/max/last samples per minute for seven days, then per hour. Old energy-only history cannot reconstruct past watts. Costs are flat-rate estimates, not utility bills.

Local AI token statistics

Token usage directly uses the MIT-licensed Tokscale core and supports all 60 local source adapters, including Codex, Claude Code, Cursor, Gemini, OpenCode, Cline, Roo Code, Kiro, Zed and GitHub Copilot. Search sources, filter by tool, inspect time buckets or expand By model. Cache and reasoning categories are included once. Some upstream adapters estimate tokens from text. Cursor requires previously synced Tokscale usage-cache files; ShowMac does not log in or sync accounts. Missing data is unavailable, not an invented zero. Statistics depend on retained local files and do not represent account quota or invoices. Scanning is offline, with a private metadata-only cache.

Token totals and allowance in your menu bar

Click the pin beside Token usage or an allowance card. In Settings → Menu bar, edit its tool, history period, quota window, icon, style and color; monochrome is the default. The popover adds a compact Token summary. Codex reads the last local account-limit report; optional Claude Code sync preserves existing status-line output and can restore the original configuration. Missing or stale reports show unavailable, not a fabricated balance. Other tools still support local history but may not provide account quota.

New in 1.18.18

Version 1.18.18 is available from the website and GitHub for Intel and Apple Silicon Macs, with macOS 11+ support.

  • Click anywhere across a collapsible section header, including the title and trailing space, to expand or collapse it. Controls inside expanded content work independently.
  • Open Scenes & apps from Thermal control or the popover control settings. Link running or installed apps to a scene, then enable Switch by app (off by default). The foreground matching app takes priority; when all linked apps quit, the previous mode returns. A manual choice pauses automation. Rules and their enabled state persist across relaunch.
  • Fan control keeps running by default. Use Set timer… for 15/30/60/120 minutes or custom 1–1440 minutes. The timer applies only to this run and is preserved across app or mode switches. Cancel it to keep running. Quitting or a failed control check returns fans to macOS; thermal protection remains active.
  • Choose a saved scene from Thermal control or the menu bar popover. Create or manage scenes… opens Scenes & apps. New scene saves the displayed curve; use a scene’s menu to rename or delete it. Deleting the active scene restores Auto. Edit the main curve to update the selected scene.
  • Restore on launch remembers the last successfully confirmed mode, including Auto, and restores it after relaunch or wake. System authorization may be requested again. Disable this checkbox to stop automatic restoration. Scenes change fan curves only, without changing Turbo Boost or power settings.
  • One curve: select CPU, GPU or both above it. Both selected means MAX, using the higher temperature. Drag to enable custom control; Auto remains managed by macOS.
  • Drag temperatures continuously, or use arrow keys for 0.1°C adjustments. Drag the rightmost point vertically to set the curve speed ceiling. Thermal protection may exceed this ceiling.
  • Settings → About ShowMac is at the bottom, with Check for Updates, the developer and GitHub. Automatic checks can be disabled; downloads open the website or GitHub in your browser.
  • Temperature modes appear when inspecting the chart. Selection menus and segmented controls share a purple style in light and dark appearances, including fonts, icons, colors, fan presets and the popover time range. Use arrows and Return to choose; Escape cancels without closing the main popover. Custom colors and images use the system panels. Intel builds retain Disable/Enable Turbo Boost in the menu bar actions.

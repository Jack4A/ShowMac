Download and open

Choose ARM64 for Apple M-series Macs or Intel for Intel Macs. Extract the ZIP and move showmac.app to Applications; quit the old copy before replacing it.

These public packages target macOS 11+. They are currently ad-hoc signed and not notarized, so macOS may report an unverified developer. Read-only monitoring needs no administrator authorization; hardware control asks when needed.

Menu bar and full app

Click the top menu bar item for cards and trends. Click a card to inspect details, or Open main window for the full app. Closing the window keeps monitoring running; Quit exits. Right-click the menu bar item for more actions.

Settings → Menu bar separates Menu bar items, Popover cards, and Font and spacing. Add icons, values or trends; edit each color and icon. Both outer and inner padding allow zero. Choose 1–8 cards independently from the top menu bar. Hold and drag a card to reorder it or drop it into the bottom removal zone.

In the development preview, the bottom pencil edits cards, the top thermal/performance status opens diagnosis, and hovering the live indicator shows the sampling time.

Fan curves and scenes

Choose Auto, Quiet, Balanced, Boost or Custom in Thermal control. Drag curve points continuously; the rightmost point sets the speed ceiling. Select CPU, GPU or both; both uses the higher temperature. Thermal protection can override your ceiling. Auto hands fan control back to macOS.

Control keeps running by default. Set timer… optionally returns fans to Auto after 15/30/60/120 minutes or a custom 1–1440 minutes. The timer lasts for this app run only. Quitting or a failed control check restores system control.

Scenes & apps saves curves for editing, gaming, office, media or coding. Link installed apps, then enable Switch by app. The matched foreground app takes priority; when linked apps exit, the previous mode returns. Manual curve or mode changes pause automation. Restore on launch remembers the last confirmed scene, but macOS may ask for authorization again.

Electricity and local AI usage

Open Usage statistics → Electricity or Token. Electricity supports Day, Week, Month and Year, with original measured power samples and recording coverage. Set your price per kWh and currency to estimate cost. Internal power readings are not a wall-outlet meter; missing intervals are not filled in.

Token history uses all 60 Tokscale local source adapters. Choose Agent and date range, sort agent statistics, or expand By model. English uses K/M/B and Chinese uses 万/百万/千万/亿/万亿. Cache hit rate is cache-read tokens divided by input tokens. Empty today does not imply no history: select another date or Year. Missing logs and web chats are outside coverage.

Use the pin beside usage or allowance to add it to the menu bar. Codex allowance comes from local quota reports; Claude Code offers optional, reversible status-line sync. Tool icons identify each account source. Expired or unavailable reports show —; token history does not imply quota support for every tool.

Settings and login startup · development preview

Settings has General, Menu bar and Features, with About, GitHub and updates at the bottom. Only one menu bar editor expands at a time. Theme, language and sampling remain in General; Preview & add opens system widgets.

Enable General → Launch at login to start quietly after signing in. If macOS requires approval, follow the System Settings link beside the switch.

Intel Macs also show Features → Turbo Boost. The switch reflects whether boosting is allowed, not current CPU frequency. Disabling requires an existing, macOS-approved com.rugarciap.DisableTurboBoost extension; ShowMac does not bundle it. Unknown states cannot be toggled. Apple Silicon hides this control.

Closed-lid mode · development preview

On an eligible MacBook, turn on Settings → Features → Closed-lid mode, or use the laptop shortcut in the popover. External power is the default condition: battery waits for power, connecting starts, unplugging stops. The enabled rule is remembered. More (⋯) includes This session only. ShowMac must remain running.

First activation requires macOS authorization. Turning it off, quitting or critical thermal pressure restores sleep. An independent watchdog and boot recovery handle interrupted sessions. It blocks system sleep, not display sleep. Desktop Macs cannot enable it. Physical closed-lid validation on supported MacBooks is still pending; keep vents clear and turn it off before packing your Mac.

Updates and privacy

Use Settings → About ShowMac → Check for updates. Automatic checks run at most daily and can be disabled. Downloads open the official website or GitHub; quit the old app before replacing it. Sensor, electricity and token data stay on your Mac.

Where is the main window?

Startup begins in the menu bar. Click its item, then Open showmac. Closing the main window keeps monitoring running. Right-click the menu bar item for actions; use Quit ShowMac to exit fully.

Choose the right download

Apple M-series Macs use ARM64; Intel Macs use the Intel download. Replace the existing app in Applications instead of running both copies. The current full desktop preview is ad-hoc signed and not notarized, so macOS may report that its developer cannot be verified. A notarized public release is not yet available.

Apple Silicon

  1. Download the ARM64 ZIP from the download section, then double-click it to extract showmac.app.
  2. Quit the existing ThermalScope or ShowMac app, move showmac.app to Applications, then open it. Your existing desktop-edition preferences use the same app identity.

Intel

  1. Download the Intel ZIP, then double-click it to extract showmac.app.
  2. Quit the existing app, move showmac.app to Applications, then open it. Do not run two fan controllers at once.

Missing readings are not zero

Sensors differ across Mac models. Use Sensors → All sensors to see what this Mac exposes. Unsupported readings remain unavailable. Recent history starts with the current session and clears on quit.

Adjust fan behavior

In the full desktop edition, choose a preset under Thermal control or drag a curve point and release to apply. Select Auto to return control to macOS. Control expires after 30 minutes. Quit other fan controllers before applying control. Apple Silicon support is experimental and depends on the model.

New in 1.18.5

Version 1.18.5 is available from the website and GitHub for Intel and Apple Silicon Macs, with macOS 11+ support.

  • Fan control defaults to Keep running. You can choose a 30-minute, 1-hour or 2-hour timer. Quitting or a failed control check returns fans to macOS; thermal protection remains active.
  • Choose a saved scene from Thermal control or the menu bar popover. Create or manage scenes… saves the displayed curve under a new name. Press Return to rename; deleting the active scene restores Auto. Edit the main curve to update the selected scene.
  • Restore on launch remembers the last successfully confirmed mode, including Auto, and restores it after relaunch or wake. System authorization may be requested again. Disable this checkbox to stop automatic restoration. Scenes change fan curves only, without changing Turbo Boost or power settings.
  • One curve: select CPU, GPU or both above it. Both selected means MAX, using the higher temperature. Drag to enable custom control; Auto remains managed by macOS.
  • Drag temperatures continuously, or use arrow keys for 0.1°C adjustments. Drag the rightmost point vertically to set the curve speed ceiling. Thermal protection may exceed this ceiling.
  • Settings → About ShowMac is at the bottom, with Check for Updates, the developer and GitHub. Automatic checks can be disabled; downloads open the website or GitHub in your browser.
  • Temperature modes appear when inspecting the chart. Selection menus and segmented controls share a purple style in light and dark appearances, including fonts, icons, colors, fan presets and the popover time range. Use arrows and Return to choose; Escape cancels without closing the main popover. Custom colors and images use the system panels. Intel builds retain Disable/Enable Turbo Boost in the menu bar actions.

Customize the two places separately

Settings → Menu bar controls icons, values and trends along the top of the screen. Settings → Popover cards controls the cards shown after clicking the menu bar item. Edit component colors, icons and spacing in Settings; cards can also be changed with Edit inside the popover.

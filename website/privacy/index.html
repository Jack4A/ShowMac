Privacy, simply.

Effective November 6, 2026

This policy covers the ShowMac desktop app and this official website. Contact: 920491071@qq.com.

The app: readings stay local

The current desktop app processes available hardware readings, system state and process activity on your Mac. It has no app account, advertising SDK, third-party analytics or telemetry upload service. ShowMac does not transmit these readings to us.

Update checks

Starting with version 1.18.4, ShowMac checks public release metadata from show-mac.cc and GitHub over HTTPS, at most once a day automatically or when you choose Check for updates. You can disable automatic checks in Settings. These requests send no sensor readings, device serial numbers or persistent user identifiers. The website host and GitHub receive the network metadata needed to serve the requests under their own privacy policies. Check time, discovered version and the automatic-check preference are saved locally. Download links open in your browser; the app does not automatically download or execute an update.

Local token statistics

Starting in 1.18.16, a bundled native Tokscale engine parses local logs, databases, exports and existing usage caches for 60 sources. Parsing may read transcript text in memory for metadata extraction or upstream estimates. The private local cache stores only token counts, dates, models, source names and hashed identities, never transcript text, API keys or login credentials. Original logs are read-only; no usage data is uploaded and no AI-provider requests, account login or usage sync is performed. Source changes are checked about once per minute; scanning can be paused.

Local account-allowance reports

Starting in 1.18.17, Codex allowance uses recent local rollout metadata: provider, limit pool, window, percentage and reset/report times. It does not read auth.json, account credentials, Keychain or account APIs. Claude Code sync is optional and off until enabled. It changes only statusLine in ~/.claude/settings.json, chains the existing command and privately saves that original configuration for restoration. The allowance cache contains only numeric quota metadata; it does not save raw status-line input or conversation text. Existing status-line commands retain their prior behavior. Reports older than 15 minutes or past reset are unavailable until refreshed.

History, settings and exports

Recent sensor charts are held in memory for up to 30 minutes and clear when the app quits. Starting with 1.18.11, electricity usage history, its measurement source and your electricity rate/currency are saved locally and retained across relaunch. Starting with 1.18.12, timestamped power history is also saved locally: real first/min/max/last samples per minute for seven days, then per hour. It survives relaunch. This history is not uploaded. Preferences, menu components, selected icons and saved fan curves are stored locally. Widget snapshots are also stored locally. If you export samples, you choose the file location and control any subsequent sharing.

This website

The website has no advertising or third-party analytics. It stores your selected language and appearance in your browser’s local storage. The hosting server keeps standard access and error logs for operation and troubleshooting. These can include IP address, request time, requested path, response status and browser information. Site-specific logs rotate daily and are retained for up to 14 days.

Anonymous website counts

We publish cumulative page views and download starts using our own counter on Cloudflare D1. We store only an approved page path (English or Chinese), or download architecture (Apple Silicon or Intel), a random event ID and the server timestamp. Our statistics database does not store IP addresses, browser details, referrers, URL query strings or persistent visitor IDs. No analytics cookies are set. Totals are retained; retry IDs expire after seven days and are removed when a later event is recorded. We respect Do Not Track and Global Privacy Control and exclude known bots and prefetches. Counts begin when this counter goes live, are not unique visitors or completed installations, and exclude direct archive and GitHub downloads.

When you contact support

If you email us, we receive the address, message and attachments you choose to send. We use them to handle your request. Email is processed by the email providers involved in delivery. You choose whether to share diagnostic samples or screenshots.

Your choices and updates

You can clear website preferences in your browser, remove local app data, or contact us about support information you have supplied. Changes to data handling will be reflected in this policy and the applicable app release.

Website language

On your first visit, our server looks up your IP address in a local DB-IP country database to choose Chinese for China, Hong Kong, Macao and Taiwan, or English elsewhere. If the country is unknown, browser language is used. This lookup does not send your IP to DB-IP. You can switch languages at any time; your choice is saved in a first-party cookie and local storage for future visits.

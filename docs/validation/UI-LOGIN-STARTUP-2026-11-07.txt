ShowMac 1.18.24 (291) — local UI and login startup validation

Changes
- General settings first: login startup, appearance, language, sampling.
- Removed the redundant settings-page introduction.
- Popover content and menu appearance expand only on request; whole headers remain clickable.
- About remains at the bottom. Existing menu composition and sensor/card settings are preserved.
- Shared 1120-point maximum reading width and a stable leading edge across main pages.
- Command-comma opens General; popover Settings scrolls to menu customization.
- macOS 13+ uses SMAppService.mainApp and displays OS registration/approval state.
- macOS 11–12 uses an opt-in per-user Aqua login LaunchAgent without KeepAlive or privilege elevation.
- Login launches stay in the menu bar; manually opening the app shows its main window.

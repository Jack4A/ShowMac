Compact menu popover cards — 2026-11-03

Scope
Replaces the three full-width graph strips in the menu-bar click popover with a two-column grid of 92-point rounded metric cards. Defaults: CPU temperature, CPU usage, maximum fan RPM, memory usage. Names and values share a row; units and real recent trends remain visible. Purple accents follow the existing light/dark palette. This supersedes earlier wide-strip popover presentation notes only.

Customization
The popover Edit button replaces the contents with an editor; no settings tab or separate window. Add from all seven built-in metrics or the current hardware inventory, with human-readable names, physical keys, units and search. Native buttons move and remove cards. Configuration saves stable identities/order, 1–8 cards, and independent visibility of fan controls and CPU process rankings. The popover height shrinks when sections/cards are hidden; larger configurations scroll within the available height.

Data behavior
Card configuration is separate from the narrow top-menu components and leaves their spacing, padding, colors and content unchanged. Sampling retains the union of physical sensors selected for menu components and popover cards. Unselected physical histories are released on the next sample. Existing bounded session history supports the popover 2/5/10-minute ranges. Zero/signed values remain valid; missing samples break lines. Warning colors use the existing CPU/GPU thresholds; no invented thresholds for power/current/fan/etc. Physical-card clicks open the sensor inventory; built-in clicks open the matching metric detail. Fan control callbacks/safety behavior are preserved.

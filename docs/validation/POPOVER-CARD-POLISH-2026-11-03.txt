Popover card visual polish — 2026-11-03

Presentation
Only StatusCards.swift and StatusOverview.swift changed. Existing card configuration, source reading/history code, native editor/settings controls and control callbacks remain intact.

- Replaced the strong gray popover background with the existing application canvas over native ultra-thin material; reduced-transparency uses opaque canvas. Both light and dark now share the main application's plum/neutral hierarchy.
- Metric cards use 12-point continuous corners, an opaque surface with a restrained highlight, a 0.6-point border and a light shadow. Increased-contrast borders remain stronger and shadows are disabled.
- Paired cards are 78 points high instead of 92; 8-point gaps replace 10-point gaps. Names and values remain on one row. Labels use 11-point medium system text and values use the existing MetricValue typography at 21 points with 10-point units.
- An odd final card spans the row at 58 points high, with its real trend to the right of the reading. Five cards no longer leave an empty sixth cell. Saved source order is preserved.
- Curves keep the same actual samples, time ranges, units, scale, gap segments and warning colors. Line weight is 1.7 points, fill fades to clear, and the last actual sample gets an endpoint marker. Endpoint lookup is performed once per chart, not per point.
- Fan controls share the quieter surface and retain the native equal-width segmented control. Removed the repeated fan heading and the extra divider above process rankings. With the current five-card setup, all three process rows are visible at the same time.

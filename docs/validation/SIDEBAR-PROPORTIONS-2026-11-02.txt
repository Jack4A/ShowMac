侧栏比例修正验证（2026-11-02）

用户反馈
用户截取传感器页面侧栏，指出当前视觉丑陋。此次仅修正侧栏比例，不扩展到其他页面。

实现
ConsoleSidebar 使用 sidebarRowSize.small 原生侧栏尺寸；移除图标独立字号、固定框和前景色覆盖，避免原生 Label 图标随环境放大而文字固定为 13 pt 的比例失衡。选中文字不额外加粗。导航与设置合为单一列表，去掉空 Section 的额外间隙。保留默认 220 pt 宽、原导航顺序、单色 SF Symbols、原生选中态和底部本机实时监测。
不更改系统全局侧边栏图标设置。
参考：https://developer.apple.com/documentation/swiftui/environmentvalues/sidebarrowsize
SDK 27 接口已确认该 API 可用 macOS 13，与最低系统版本匹配。

# 温控台 · ThermalScope 1.15

本地 Mac 温度、性能与能耗诊断工具。默认实时指标与趋势，侧栏直接进入温控、性能诊断、进程和记录；诊断先展示指标和依据，再连接到可审阅的操作。设置集中管理主题、语言、状态栏和采样频率。

## 使用

打开同级目录 ThermalScope-1.15-final.app（下载压缩包内名称为 ThermalScope-1.15.app）。新版启动会请求同标识的旧版正常退出，避免多个硬件控制者；关闭窗口后仍在菜单栏监测。旧版本和源代码压缩包保留。

页面直接放在侧边栏，按常用场景进入：
- 实时监测（默认）：CPU 温度、GPU 温度、存储温度、内存、风扇转速、CPU 使用率六组真实指标；当前模式、睿频、系统低电量状态和多来源温度趋势。
- 温度控制：系统自动/节能/性能/静音，独立睿频和风扇控制。
- 性能诊断：同一次规则评估的指标、有效观察时长、发现与依据，可审阅优化、效果与恢复。
- 进程活动：CPU/内存/磁盘排行、应用及关联子进程审阅、负载依据。
- 操作记录：最近事件及采样导出；设置在侧栏底部独立进入。
主导航采用原生 NavigationSplitView 和侧栏 List；系统工具栏提供返回与刷新，保留系统侧栏折叠与分栏调整。没有重复的横向主导航。六项指标卡均进入对应的指标详情及历史图表，模式入口进入温控。CPU 使用率详情保留前五项进程来源，并可继续打开完整 CPU 排行；内存详情可继续查看内存排行。切页不清空采样历史或控制状态。
诊断建议可定位相关应用和子进程、内存排行、温度曲线、休眠来源或准备节能方案。正常退出应用需要独立确认，并检查进程身份和所属应用；不会因诊断自动结束程序。

## 指标详情与状态栏

CPU、GPU 和存储温度详情固定对应来源，提供 5/10/30 分钟趋势、真实悬停温度、模式分色、睿频关闭虚线及切换标记；可展开传感器读数。CPU 使用率、内存、风扇、电池详情使用真实时间戳历史；百分比默认固定 0–100%，风扇图显示可读风扇最高转速，并列出各风扇读数、额定范围与自动/手动状态。最低、采样均值和最高值均来自当前窗口完整实际采样，不补造历史。首页六项卡片附带最近 2 分钟短历史。

温度和其他指标图均提供原生“固定刻度/自动刻度”“线条/面积”分段选择，以及暂停图表/继续实时按钮。暂停只定格当前图表的样本、时间范围和统计，后台监测与硬件控制继续运行；来源或时间范围变化、离开页面时恢复实时。悬停从完整样本查找真实采样时间和值，不拿绘图降采样后的近似值替代；超出数据范围或断档附近没有足够接近的样本时不显示假读数。固定刻度保持比较口径，自动刻度会放大局部变化并明确显示纵轴；两种刻度都保留实际高值。

状态栏支持可开关的最近 2 分钟迷你曲线，默认 CPU 使用率，可选择 CPU/GPU/存储温度、内存、风扇或电池；支持线条、面积、柱形和紧凑/标准/宽三种宽度。百分比固定 0–100%，温度默认 0–130°C、风扇默认 0–6000 RPM，超出默认上限的实际读数会扩展上限。与设置中的实时预览共用原生 AppKit 绘制器，配置持久保存。图像使用 template 自动适应系统菜单栏颜色。左键点击状态栏直接打开原生 NSPopover 图形面板，以状态按钮 bounds 为锚点，由系统定位。面板同时显示温度、全机 CPU 负载和风扇最高转速三张真实历史图；支持 2/5/10 分钟，温度可选择 CPU/GPU/硬盘，范围与来源会保留。每个风扇显示实际 RPM、自动/手动状态与相对额定最高转速的容量指示；主要 CPU 来源可继续进入详情。顶部显示本应用确认的运行模式或实际外部控制状态、睿频状态。

点击曲线或数值进入对应指标详情，模式与温控按钮进入温控；设置按钮打开设置。点击外部或 Escape 收起，关闭后释放图表视图和订阅；继续复用主应用既有采样，不新增轮询。短屏时内容区可滚动，底部入口固定。右键或“更多操作”保留原生快捷 NSMenu；信息行依旧启用并可导航。

非温度历史保留最近 30 分钟、最多 1000 点；内存和电池只按实际遥测时间记录，不把旧值重复计为新样本。缺失、非有限读数和采样断档断线显示。不同指标采样均值不等于加权能耗或功率测量。

## CPU 负载警示色（1.15）

菜单栏 CPU 曲线、面积、柱形和圆环，以及首页 CPU 短趋势、展开面板和完整 CPU 详情使用同一显示规则：全机使用率达到 70% 显示橙色，达到 90% 的连续有效采样满 10 秒显示红色，下降后恢复对应级别。缺失、无效值、采样分段或超过 15 秒的断档会重计持续时间。阈值属于显示分级，不是过热或限速的诊断依据。

历史按确认采样分段着色，不把整条曲线回染。先在完整采样上判断持续时间，再保留颜色边界降采样；新级别从实际确认样本开始，单个新分段也有可见标点。统计、暂停与悬停继续读取原有完整样本。CPU 高负载警示色默认开启，可在状态栏设置关闭。其他指标保持配置配色。

系统单色方案在警示片段存在时保留警示色，普通图形和文字仍按状态按钮自身外观显示；关闭警示或窗口内不再有高负载后恢复 template。该功能不新增采样计时器、系统通知或硬件动作。

## 菜单栏外观（1.14）

本轮聚焦屏幕顶部常驻菜单栏的图形与搭配。每项指标独立选择双行数值、仅数值、仅图标、面积历史、柱形历史、圆环与数值或曲线与数值。极简、曲线组合、仪表组合提供真实数据缩略图，点击即应用样式及项目组合；不会改变硬件模式。

支持系统单色、统一紫和多彩，紧凑/标准间距、三档图宽及图形底色。多彩模式可使用原生 ColorPicker 为各指标调色；其他配色禁用逐项颜色，避免与主题冲突。项目启用、顺序和样式独立保存。新配置默认自定义组合，已有显示配置保留；在设置中选择自定义组合或使用自定义组合按钮进入新外观配置。

浅、深菜单栏预览按实际尺寸显示，复用实际 NSStatusItem 的 AppKit 绘制器。图形使用最近两分钟真实有界历史，柱形按像素桶保留峰值，缺失无填造历史；圆环只表示实际数值在图表刻度内的位置，不是健康评分。温度基准刻度 0–130°C，百分比 0–100%，风扇基准 0–6000 RPM；超出基准的真实数值会扩展上限。数值预留固定数字宽度，减少读数变化造成的菜单栏抖动。颜色用于图形，文字跟随菜单栏自身的系统外观，系统单色使用 template 自动适配。

仍为一个组合 NSStatusItem，系统 Cmd 拖动移动整个组合；组内顺序在设置调整。没有声称每个子项都是独立系统状态项。曲线/数值更新复用现有采样，不新增计时器、CPU 扫描或旋转动画。

## 紧凑状态栏（1.13）

参考 iStat Menus 官方界面的紧凑信息分区，独立实现本应用已有指标。菜单栏新增双行标签＋数值（新配置默认），也保留图标/数值等既有选择，已有用户偏好不强制改写。双行由原生 AppKit template 图像绘制，设置预览共用同一绘制器，跟随系统菜单栏文字颜色；图形仍可选择来源、线/面积/柱形和宽度。

原生 NSPopover 宽度收紧到 360pt，采用系统材质、轻描边、小标题与右对齐读数。温度、CPU 和风扇图使用真实短历史、固定范围和缺失断线；模式/睿频在顶部，逐风扇读数及自动/手动状态在风扇区，CPU 前三来源放末尾。进程数值按单个核心 100% 计，和全机负载口径明确区分；过期进程采样不展示。底部保留采样时间、详情/温控、设置与更多操作入口。温度来源与 2/5/10 分钟仍可选。

减少透明度时使用实体表面；短屏内容可滚动、隐藏滚动条、底部入口固定。面板关闭后释放视图订阅，不新增采样轮询或持续动画。参考的是信息层级和密度，不附带或复用 iStat 的图标、资源、代码，也不展示未采集的核心/功率/频率数值。

## 系统状态小组件（1.12）

新增独立 WidgetKit 扩展，面向桌面（macOS 14+）与通知中心（macOS 13+）。小尺寸显示 CPU 温度、使用率、最高风扇转速和负载短趋势；中尺寸展示温度、CPU、风扇三条曲线；大尺寸补充逐风扇自动/手动状态、GPU 和存储温度。中、大尺寸显示模式和睿频。点击指标进入详情，小卡整体打开实时监测。URL 只允许导航，不执行硬件操作。

设置中的“系统小组件 → 预览与添加”提供三种尺寸预览及系统添加说明。桌面空白处右键 → 编辑小组件 → 搜索“温控台”，也可从通知中心底部添加。主应用需运行新版才能持续提供状态；本轮未重启正在运行的 1.11 控制会话。

小组件显示最近采样，不承诺秒级实时：主程序复用既有采样，普通快照最多每分钟写一次，常规请求每半小时刷新；模式或睿频变化合并请求，至少间隔一分钟，实际执行由 macOS 决定。卡片始终显示采样时间；旧数据、应用退出和不可用状态明确区分。关闭主程序后标记暂停，超过一天不显示旧数值。只保留五分钟有界趋势，不补造历史。

组件不启动辅助进程、不访问传感器或硬件控制。当前本地 ad-hoc 版使用沙盒和仅限本应用 WidgetSnapshots 子目录的只读文件例外；共享摘要不包含进程名单、凭据或操作日志。快照目录为 ~/Library/Application Support/ThermalScope/WidgetSnapshots，目录/文件权限分别为 700/600。

正式签名时可提供 THERMALSCOPE_SIGN_IDENTITY 和 THERMALSCOPE_APP_GROUP，主程序及扩展使用真实获准的共享容器，构建脚本移除文件读取例外；不伪造 Team ID。本地编译、注册、沙盒读取及最终真实数据组件在 Apple WidgetKit Simulator 系统宿主的小中大显示已通过，实际趋势及暂停标识可见。系统宿主证据为 widget-native-medium-1.12.png；布局预览另列在 widget-previews-1.12。桌面/通知中心图库添加、深色与链接跳转尚未完成验收：操作工具无法访问桌面/通知中心窗口，当前旧版控制会话未重启。系统缓存仍将父应用名显示为 ThermalScope-1.11-final，已核对实际扩展路径为 1.12-final；正式启动新版后的图库名称待确认。见 PLAN-WIDGETS-1.12.txt。

## 诊断依据

规则输出已确认、可能相关或数据不足，不生成健康分。
性能诊断以“指标→持续诊断→审阅措施→观察效果”组织。DiagnosticMetrics 捕获与规则同次输入的全机 CPU、CPU/GPU 温度、内存压力、热压力/性能限制，以及窗口内主要 CPU/磁盘来源；过期进程指标和无效数值保持未知。全机 CPU 的 100% 指所有核心，应用均值按单核 100% 计，CPU 活动不代表实际功率。点击指标可进一步审阅来源，优化措施需检查后执行。
- 持续 CPU：按单核 100% 计，应用与子进程合并；至少 45 秒可读观察、平均达到一个核心且当前仍有较高活动时提出查看建议。编译、渲染可能是正常任务，不能据此判定恶意程序。
- 温度：CPU 80°C / GPU 75°C 起提示继续观察；CPU 90°C / GPU 85°C 持续 30 秒才形成持续高温建议。系统热压力及性能上限单独判断，关闭睿频本身不等于系统过热或限速。
- 内存：读取系统真实内存压力等级，不根据已用内存百分比推断压力。接口不可用时保持未知。
- 磁盘：读取进程累计磁盘字节并计算差分速率；有效观察至少 30 秒、均值 20 MiB/s 且当前仍在传输时作为信息展示，不自动判定磁盘故障。
- 休眠阻止：原生 IOPM 请求只说明谁在保持唤醒，远程、会议、播放和下载可能合理。
- 电池：低电量且未启用低电量模式时可准备对应方案；建议不会自行写设置。
缺失、过期、重用的 PID 和采样断档不当作零或正常。仅覆盖有权限读取的进程。

## 优化与恢复

默认不勾选系统措施；可由建议准备方案，也可手动选择并审阅每项原值→目标值。
可选系统低电量模式、当前供电或电池开启/插电关闭、显示器闲置 5 分钟休眠、系统闲置 15 分钟休眠、额外关闭 Intel 睿频。存在保持唤醒任务时不允许调整系统闲置休眠；原风扇策略保持不变。
同一个编译型原生授权辅助进程执行固定参数的 macOS pmset 命令，不提供 shell 或任意命令入口。首次控制由系统请求管理员授权，本次应用运行内复用；应用退出后不保留会话，下一次运行首次控制可能再次要求授权。不存储密码。
供电/原值变化会拦截；修改后读回确认，部分失败尝试回退。成功后保存本机恢复记录，重启软件后可恢复；外部修改过的不同值不会覆盖。电源配置退出软件后仍保留，使用恢复按钮撤回。

效果观察由辅助进程记录实际开始执行的时刻，使用此前最多一分钟的采样，排除等待授权的时间。应用后等待 10 秒，再观察最多 60 秒。样本不足、供电不同或负载变化较大时不作效果归因；插电/充电/电池样本不足时不生成放电瓦数或省电百分比。

## 温控功能

系统自动保留当前睿频设置；节能禁用睿频并采用均衡风扇曲线；性能允许睿频并积极散热；静音禁用睿频并温和散热。睿频也可独立切换。
风扇控制页直接提供“温度°C → 转速%”逐点设置，温度及百分比可输入，百分比也可通过对应行滑杆调整；独立的固定 50% 滑杆已移除。可跟随 CPU、GPU 或两者较高温，选择性能/均衡/静音预设，并展开曲线图。现有用户曲线会保留，新配置默认为均衡曲线。两点之间线性插值，转速随温度升高不降低，最终保护点在不高于 90°C 时达到 100%。0% 是额定最低转速，不代表停转。
编辑保存为草稿，点击“应用曲线”后才执行硬件操作；实时显示的是草稿的曲线目标，保护规则可覆盖目标。应用中等待硬件确认，只有收到成功回复且确认所属会话后才保存已应用曲线状态；失败或会话结束会清除确认缓存。草稿编辑不会重启控制会话，应用时保留当前睿频选择。系统自动始终保留。会话最长 30 分钟；退出、睡眠、读数失效、主进程消失或到期时请求恢复自动风扇。睿频选择保留。强制结束辅助进程或硬件故障不能保证恢复。
温度趋势支持 CPU/GPU/存储/电池，5/10/30 分钟；模式分色、关闭睿频阶段虚线、切换标记和真实悬停读数。没有模式对比页面。

## 设置、性能与数据

界面以 Palette.swift 集中管理灰紫色调：中性画布、统一表面/边框、紫色图标与选中态、用于白字主操作的更深按钮色。普通指标使用主文字色，告警仍保留橙红语义；曲线用相关的低饱和模式色和图例区分，关闭睿频虚线保留。深浅主题共用同一组颜色角色。

支持跟随系统/深浅主题及简中、繁中、英语、日语、韩语、德语、法语、西语，切换无需重启。语言、主题、采样频率合为紧凑设置行；主题和采样使用原生分段控件。菜单栏预览与样式并排，项目按实际显示顺序列出，箭头移动后列表和预览同步。预览支持横向滚动。实时指标卡提供详情箭头和悬停反馈。导航、工具栏、菜单、选择器、分段选择、复选框、滑杆和折叠控件优先使用系统组件；系统版本支持时由原生组件采用当前系统的 Liquid Glass 外观。图表和指标内容保持清晰的实体表面，使用细描边、轻阴影和静态环境渐变增加层次。减少透明度开启时回退实体表面；不新增持续动画或额外轮询。应用内滚动指示器隐藏，保留原生滚动和可访问内容，不改变系统全局滚动条设置。编译使用公开 SDK 26.5，部署兼容 macOS 13+；不声称使用未验证的 macOS 27 专属 API。
新配置默认 5 秒采样，可选 2 秒；保留已有用户选择。采样、进程扫描在后台运行，读数、诊断、曲线、进程分别刷新；温度曲线及其他指标分别以保留峰谷和分段端点的方式降采样，降低绘图点数；统计和悬停使用完整样本。记录只在本机内存保留最近 30 分钟，恢复记录保存本机，不联网遥测。

## 开发

构建：`bash scripts/build.sh /absolute/path/ThermalScope.app`
检查：`swift run -c release ThermalCoreChecks`
只读诊断参数：`--probe`、`--system-probe`、`--process-probe`、`--power-probe`、`--localization-check`、`--status-menu-check`。后者只构造并验证真实原生菜单的信息行启用状态及路由，不启动窗口、不调用控制动作。
Diagnostics.swift 为无副作用规则领域层；DiagnosisStore.swift 负责限频观察；DiagnosticViews.swift 负责解释和审阅；AppModel.follow 仅路由类型化动作；PowerOptimizationModel 和原生辅助进程保留受控操作、确认与恢复。

组件只读检查：`--widget-data-check`；`--widget-publish-once` 写一次真实但标为暂停的摘要；`--widget-preview-feed` 是三分钟只读真实采样验收工具，结束标记暂停；`--widget-render-previews /absolute/path` 仅离屏渲染共享布局，不是系统宿主截图。

菜单栏原生绘制检查：`--menu-appearance-check`，只读实际样本与缺失样本，在不同样式/配色/宽度下强制生成图像及校验颜色编码，不写入偏好或硬件。

CPU 警示绘制检查：`--cpu-warning-check` 使用明确的测试夹具验证浅深背景线/柱形保留正常与橙红像素，以及单色保色、关闭开关、非 CPU 指标和旧曲线样式。夹具不写入实时监测或硬件。

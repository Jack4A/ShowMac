# 1.18.14 usage statistics UI previews

Chinese/English, light/dark previews of Live metrics, the combined usage page and the focused Token usage section, rendered from the native app with isolated fixtures via `--compatibility-ui-check --ui-check`. Energy, token counts, example model names and the CNY 0.60/kWh rate are sample data. Real private conversation histories, hardware controls and saved preferences were not changed by captures. The local token scanner is disabled during fixture rendering.

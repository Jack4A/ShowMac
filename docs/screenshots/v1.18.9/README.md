# ShowMac 1.18.9 UI previews

Rendered November 5, 2026 from the shared build-276 SwiftUI views with isolated fixture readings on macOS 27. These are UI previews, not live hardware measurements. English and Simplified Chinese previews use their respective localization. Five example metric cards and fan controls are visible; process rankings are hidden. The timer input preview uses a sample 30-minute timer assigned only for rendering, without scheduling a callback or controlling hardware.

The updated controls replace the saved continuous/duration selector with Set timer…. Default control has no deadline; custom one-shot timers can be cancelled and are not saved across app relaunch. Theme, locale and capture configuration are isolated from the installed app. Other website screenshots keep their previously documented provenance.

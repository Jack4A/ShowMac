# ShowMac 1.18.17 UI previews

Captured by `--compatibility-ui-check --ui-check` from the 1.18.17 / 284 local development build on macOS 27. English and Chinese images use their corresponding app locale, in light and dark appearances. These are native AppKit/SwiftUI renders, not HTML mockups.

All hardware, electricity, token and allowance values are synthetic fixtures. The example electricity rate is CNY 0.60/kWh. Codex 5-hour/7-day windows are illustration data; the app uses actual reported periods in use. No private sessions, real usage or process identities appear in these public images. Claude Code sync is not enabled by the fixture.

The same macOS 11 release binary is rendered on macOS 26/27 by CI. This local SDK 27 build targets macOS 12 and is not the public release package. Layout captures do not certify a physical macOS 11/12 runtime.

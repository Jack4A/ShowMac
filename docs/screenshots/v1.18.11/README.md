# 1.18.11 electricity usage previews

Chinese and English light/dark captures of the shared Electricity usage page, rendered by `--compatibility-ui-check --ui-check` with isolated sample power readings and an example CNY 0.60/kWh rate. These previews illustrate the UI and are not measurements of the developer’s or a customer’s electricity use. No hardware controls, real usage history or saved preferences were changed. Real records start when the updated app runs; gaps are not backfilled.

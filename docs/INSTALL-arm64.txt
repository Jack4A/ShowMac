简体中文
1. 打开 https://show-mac.cc/zh/#download，下载 showmac-1.18.12-macOS-arm64.zip，也可从 GitHub Releases 下载。
2. 解压，将 showmac.app 拖到“应用程序”后打开。仅用于 Apple Silicon Mac。
3. 点击顶部状态栏图标，从面板打开控制台；在“设置 → 语言”选择简体中文或 English。
4. 此版本支持实验性独立风扇档位与温度曲线；首次接管需要系统管理员授权，可从“风扇测试”执行 5 秒验证。选档立即生效，拖动曲线松手后生效，默认持续控制，退出时交回系统；可选定时结束，重启后可恢复所选场景。Intel 睿频和电源设置控制仍禁用。
5. CPU/内存/进程/电池等可用读数依赖系统接口；温度和风扇传感器可能不可用，缺失值保持缺失。

硬件验证范围见源码 docs/APPLE_SILICON_FANS.txt；构建清单中的静态检查不代表每台Apple Silicon机型都已验证。
已检查主程序、辅助程序及小组件均为 arm64，签名与归档解压完整性通过；这不能替代 ARM 真机功能和性能验证。
当前为 ad-hoc 签名，未经 Apple 公证，macOS 可能提示无法验证开发者。
与 Intel 版共用应用标识，安装时替换同名应用；不要同时运行两个版本。
完整下载本架构四个附件后运行：shasum -a 256 -c SHA256SUMS-arm64.txt。

English
1. Open https://show-mac.cc/en/#download and download showmac-1.18.12-macOS-arm64.zip, or use GitHub Releases.
2. Extract it and drag showmac.app into Applications. This package is for Apple Silicon Macs.
3. Click the menu bar item and open the console from its panel. Select English or Simplified Chinese in Settings → Language.
4. This version supports experimental independent fan presets and temperature curves. Authorize through macOS on first use; a five-second verification is available under Fan test. Presets apply immediately, curve edits apply on release, and control continues until stopped or the app quits; timers and relaunch restoration are available. Intel Turbo and power-setting controls remain disabled.
5. Available CPU, memory, process and battery readings depend on system interfaces. Temperature and fan sensors may be unavailable; missing readings stay missing.

See docs/APPLE_SILICON_FANS.txt in the source for hardware validation scope; static build checks do not validate every Apple Silicon model.
Architecture checks confirm arm64 host, helper and widget binaries. Signatures and archive extraction integrity were checked; these do not establish ARM runtime functionality or performance.
The package is ad-hoc signed and not notarized. macOS may report that the developer cannot be verified.
It shares the Intel build's application identifier; replace the existing app rather than running both versions.
Download all four arm64 assets into one folder and run: shasum -a 256 -c SHA256SUMS-arm64.txt.

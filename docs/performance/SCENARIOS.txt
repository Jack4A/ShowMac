温控台可重复性能测试集 — 1.16 / 2026-10-31

目的与范围
分开验证静态后台、可见监测、弹层、设置预览和曲线交互。功能检查不替代性能检查。默认测试只观察主进程，不操作硬件、不关闭其他应用、不生成 CPU 压力。
CPU 百分比按单个核心 100% 计；全机百分比需除以逻辑核心数。唤醒、CPU 和 I/O 是能耗代理，不能转换成省电百分比。ri_energy_nj 仅在可读且实际增长时换算该进程焦耳/瓦数；零或不支持记录 unavailable。它不等于整机电池功耗。

固定条件
release 构建、相同机器/供电/主题、5 秒采样、相同菜单配置；每场景预热至少 10 秒，首次基线可先用 30 秒样本，正式回归建议每次 120 秒、至少 3 次，交替版本顺序。记录二进制哈希、系统版本、供电、采样配置、其他负载、窗口可见状态、开始时间。不要把单次短样本当成长期能耗或因果 A/B 结论。
测试副本使用不同 bundle ID，移出特权辅助程序和 WidgetKit 扩展；因此测量范围是主应用，不包含 WidgetKit/WindowServer 或控制辅助进程。正式发布须另做完整系统范围的对照。

场景
B01 后台静置：窗口最小化/关闭，菜单监测继续；分别记录配置，不能混称。
B02 可见实时监测：不操作，等待周期采样。
B03 原生状态弹层：三张图、进程信息显示，不操作。
B04 设置：浅深菜单预览和三套缩略图显示。
B05 曲线交互：通过 UI 打开编辑，拖动/输入/切换预设、滚动、关闭；只改测试副本的草稿，不点击应用/恢复/模式/睿频。
B06 长时：B01/B02 各 30 分钟，采样稳定后观察内存趋势、进程扫描及订阅释放，至少 3 轮。
B07 真实流畅度：用 Instruments Animation Hitches/Core Animation 采集滚动、弹层开合、曲线拖动；记录屏幕刷新率、p95/p99 帧时、hitch 总时长及比例。没有这些工具时记录未测，不能用显示回调频率当 FPS。
B08 电池/插电与睡眠恢复：相同场景复测，供电切换不混合比较；不自动让用户机器睡眠或断电。

外部进程采样（无需管理员权限）
xcrun clang -O2 tools/perf-sample.c -o /absolute/work/perf-sample
python3 scripts/perf_capture.py --pid PID --seconds 120 --warmup 10 --scenario B01 --sampler /absolute/work/perf-sample --app /absolute/path/Test.app --out /absolute/results/B01
每秒记录 CPU 时间、物理 footprint/RSS、包 idle/中断唤醒、磁盘字节、进程启动身份和可用能耗计数；PID 重用/倒退失败。原始 samples.csv 与 summary.json 一并保留。
python3 -m unittest discover -s Tests/Performance -v 校验单位、能耗缺失、PID 复用、所有单调计数器倒退、分位数及预算判定（8 项）。
python3 scripts/perf_assess.py /absolute/results/B01/summary.json --out /absolute/results/B01/assessment.json
按场景生成观察预算结果，超标为 needs_investigation；短样本和缺失功耗/帧数据均不能输出正式回归通过。正式门禁需要跨场景汇总人工复核。
ThermalScope.app/Contents/MacOS/ThermalScope --hidden-view-update-check
独立测试夹具连续收集 120 条隐藏窗口数据，核对无视图通知、历史不丢失、恢复可见时读数与温度时间线一次追上最新；不启动监控实例或写硬件。

主线程观察（仅测试副本启用）
在测试副本 Info.plist 加 ThermalScopePerformanceDirectory=/absolute/results/loop 并重签名。通过原生“窗口→开始性能观察/结束性能观察”采集。正式包没有此字段，不安装观察器、不显示测试入口。
被动 CFRunLoopObserver 记录唤醒到睡眠间忙碌跨度 p95/p99/max、超过 16.7/100ms 的次数，不新增采样计时器。少于 20 个跨度不输出分位数。此值是主线程响应代理，包含调度/工作跨度，不是实际渲染帧率、动画 hitch 或系统流畅度评分。

离屏渲染
ThermalScope.app/Contents/MacOS/ThermalScope --render-performance-check
固定测试夹具，预热 20 次，测量 200 次原生菜单图像生成/CPU 位图绘制和 900 点 CPU 分级降采样的 p50/p95/max。它不包含合成器/GPU、真实窗口动画，不是 FPS。

首轮观察预算（产品目标，非 Apple 标准）
B01 平均 CPU ≤1% 单核、平均唤醒 ≤20/s；B02 平均 CPU ≤3%、B03 ≤5%、B04 ≤5%。内存预热后稳定，长时增长 ≤5 MiB/分钟且不持续线性增长。交互主线程忙碌跨度 p95 目标 ≤16.7ms、不得出现持续 >100ms；这不替代真实帧时预算。
首次短样本仅生成警告/基线，不硬性据此宣称通过长期门禁。指标超过预算必须调查，不通过调高目标掩盖。

当前环境限制
仅有 Command Line Tools，xctrace/Instruments 未安装。powermetrics 要求 root，当前没有为本轮申请管理员权限。本机进程能耗计数返回零时不输出虚构瓦数。真实功耗/帧卡顿、长时和多供电场景需保留为发布门禁。
参考 Apple Energy Efficiency Guide、Power Profiler、AppKit 系统字体文档。

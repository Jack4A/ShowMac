## Apple Silicon arm64 补充包 / ARM64 add-on

新增 **`ThermalScope-1.16.0-macOS-arm64.zip`**，最低 macOS 13，主程序、辅助程序和小组件均为原生 arm64。

**这是实验性监测版，由 Intel Mac 交叉编译，尚未做 Apple Silicon 真机启动、功能或性能验证。风扇、睿频和电源设置控制已禁用。温度、风扇等读数依赖机型接口，可能不可用。** 当前为 ad-hoc 签名，未经公证。

附件：`INSTALL-arm64.txt`、`release-manifest-arm64.json`、`SHA256SUMS-arm64.txt`，与 ARM ZIP 一起下载后运行 `shasum -a 256 -c SHA256SUMS-arm64.txt`。已校验三部分的 arm64 架构、代码签名、ZIP 解压后完整性和动态库依赖；运行时检查明确标为未执行。

ARM 对应源码：[v1.16.0-arm64](https://github.com/Jackkakaya/ThermalScope/tree/v1.16.0-arm64)，确切提交见 ARM 清单。Intel 的原发布标签和四个附件保持原样。仓库保持 **Private**。

### English

Added **`ThermalScope-1.16.0-macOS-arm64.zip`**, targeting macOS 13+, with native arm64 host, helper and widget executables.

**This is an experimental monitoring-only build, cross-compiled on Intel. It has not been launched or functionally/performance-tested on Apple Silicon hardware. Fan, Turbo and power-setting control are disabled. Temperature and fan readings depend on model-specific interfaces and may be unavailable.** Ad-hoc signed, not notarized.

Download `INSTALL-arm64.txt`, `release-manifest-arm64.json` and `SHA256SUMS-arm64.txt` with the ARM ZIP, then run `shasum -a 256 -c SHA256SUMS-arm64.txt`. Architecture, signatures, archive extraction and dynamic dependencies are checked; runtime checks are explicitly unexecuted.

ARM source: [v1.16.0-arm64](https://github.com/Jackkakaya/ThermalScope/tree/v1.16.0-arm64), with the exact commit in its manifest. The original Intel tag and four assets are unchanged. The repository remains **Private**.

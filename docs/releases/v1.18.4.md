# ShowMac 1.18.4 · build 271

- Add **Check for Updates…** to the ShowMac application menu and menu bar actions, plus an inline update section in **Settings → About ShowMac**.
- Check the official website and public GitHub release metadata, selecting the newest stable numeric version. Either source can work when the other is unavailable. Drafts, prereleases and malformed responses are ignored.
- Enable a quiet background check at most once per day, with an option to turn it off. An available update appears in Settings and in the menu bar popover footer; startup checks do not interrupt with alerts.
- Offer **Download from website** and **Download from GitHub**. Updates are downloaded in the browser and installed by replacing the app; ShowMac does not download or execute an installer automatically.
- Keep discovered versions across restarts and handle network failures without claiming that the installed app is current. No sensor readings or persistent visitor identifiers are sent when checking versions.
- Move About ShowMac and update checks to the bottom of Settings, with the developer and GitHub link.
- Allow continuous curve-point temperatures and an adjustable maximum-speed endpoint within each fan's rated range. Arrow keys fine-tune by 0.1°C or one percentage point of the rated speed range; thermal protection can still request full speed.
- Keep a single curve with native CPU/GPU checkboxes. Selecting both uses the highest temperature. Recognize verified Apple M4 CPU/GPU probes in monitoring, diagnosis and control, without guessing unknown probe identities.
- Replace large chart filter controls with compact native menus and move the unit beside the chart title. Show temperature-series modes on inspection instead of a persistent legend.
- Preserve Disable/Enable Turbo Boost actions in Intel builds.

Intel and Apple Silicon packages continue to target macOS 11+. Packages are ad-hoc signed and not notarized. Read the installation guides for macOS security prompts and hardware support limits.

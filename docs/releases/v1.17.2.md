# ThermalScope v1.17.2

Build 263 · Intel x86_64 + Apple Silicon arm64 · macOS 11+

## 简体中文

- 以用户认可的深色界面为基准，在所有支持的 macOS 版本上统一主体外观。
- 侧栏使用不透明主题底色、固定深色选中态和 220 pt 宽度，设置固定在底部；保留原生表格的点击、键盘导航与无障碍操作。
- 内容区使用同一套背景、左侧圆角和细边界，避免系统分栏与玻璃材质改变层次。
- 所有趋势、卡片和风扇曲线共用同一绘制实现，保留真实采样、缺失断线、警告色、暂停、读数查询和拖动调速。
- CI 使用同一份构建在 macOS 26、27 的真实标题栏窗口中渲染 14 个浅深色场景，比较侧栏宽高、位置、底部设置位置与实际颜色；外观检查未通过时不会发布。

主程序、辅助程序和小组件继续以 macOS 11.0 为最低部署目标。macOS 11/12 已执行 API 编译与兼容路径检查，真机运行验证仍待完成。系统窗口按钮和标准控件继续由 macOS 提供。Apple Silicon 风扇控制保持实验性、按能力开放；Intel 包为交叉编译。安装包沿用 ad-hoc 签名，未公证。

## English

- Unifies app chrome across supported macOS versions using the approved dark appearance as the reference.
- Uses an opaque themed sidebar, a fixed dark selection, 220 pt width and bottom Settings, retaining native table interaction and accessibility.
- Shares content backgrounds, leading corners, borders and one chart renderer across macOS 11+, preserving real samples, gaps, warning colors, pause, inspection and draggable fan curves.
- CI renders the exact same checked binary in titled windows on macOS 26 and 27 and compares fourteen light/dark layouts, sidebar geometry, Settings position and measured colors before publication.

App, helper and widget continue targeting macOS 11.0. Physical-device validation on macOS 11/12 remains pending; native window buttons and standard controls remain system-provided. Apple Silicon fan controls remain experimental and capability-gated; Intel is cross-compiled. Packages remain ad-hoc signed and not notarized.

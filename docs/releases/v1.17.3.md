# ThermalScope v1.17.3

Build 264 · Intel x86_64 + Apple Silicon arm64 · macOS 11+

## 简体中文

- 按用户最新确认的截图修正外观方向：侧栏恢复柔和的灰紫通透感，选中项使用更亮的灰紫高光。
- 删除 v1.17.2 新增的侧栏外围描边，保留主内容区靠侧栏的圆角和细边界。
- 所有支持版本共用同一套侧栏材质、主题着色和选中渐变；减少透明度时使用清晰底色。
- 保留既有字体、内容布局、图表、菜单栏组件、卡片配置与调速逻辑。
- macOS 26、27 继续以同一份构建执行 14 个浅深色场景检查；回归检查会拒绝此前方向错误的深色选中态。

最低部署目标仍为 macOS 11.0。旧系统尚未逐版真机验证。Apple Silicon 风扇控制保持实验性、按能力开放；安装包沿用 ad-hoc 签名，未公证。

## English

- Corrects the visual direction to the latest user-provided reference: a softly tinted translucent sidebar and a lighter gray-plum selection highlight.
- Removes the extra sidebar outline introduced in v1.17.2, retaining the leading content corners and subtle boundary.
- Shares sidebar material, tint and selection gradient across supported systems, with an opaque Reduce Transparency fallback.
- Preserves typography, content layout, charts, saved menu/card configuration and fan-control behavior.
- Continues fourteen light/dark cross-version captures on macOS 26 and 27; regression checks reject the previous reversed dark selection.

The minimum deployment target remains macOS 11.0; older systems have not all received physical-device validation. Apple Silicon fan controls remain experimental and capability-gated. Packages remain ad-hoc signed and not notarized.

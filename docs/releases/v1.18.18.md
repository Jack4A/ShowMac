# ShowMac 1.18.18 · build 285

- Use Chinese magnitude units (万 / 百万 / 千万 / 亿 / 万亿, with Traditional Chinese equivalents) throughout token totals, cards, tool distribution, the menu bar and its popover. English keeps K/M/B; exact sample/model counts stay unabridged.
- Split Usage statistics into Electricity and Token tabs. The compact homepage summary opens each tab directly.
- Refresh electricity presentation with separate energy, estimated cost and average-power cards, plus the measured power chart.
- Add token input/output/cache cards, hourly trends and a tool distribution view, retaining all 60 local source adapters and model details.
- Pin token totals or provider-reported remaining allowance to the menu bar. Choose the tool, reporting period, icons, colors and display style in the component editor. Defaults remain monochrome. The popover adds a compact Token summary when a Token component is configured.
- Read Codex allowance snapshots from recent local rollout records. Use the actual reported period instead of assuming a five-hour window. Keep independent model pools separate from shared account limits. Do not derive account quota from token totals.
- Offer optional, reversible Claude Code status-line sync. Preserve the existing command output and save only quota metadata in the allowance cache. Keep the original status-line configuration privately for restoration; other settings keep their values. No OAuth, Keychain or browser-cookie access is added.
- Treat missing, expired or reset snapshots as unavailable. Do not invent a 100% refill or infer an absolute token balance. Current allowance is independent of the selected historical date range.
- Cache native engine builds in CI by full engine sources, locked dependencies, architecture, macOS floor, SDK and compiler version.

Sources: [Codex rollout protocol](https://github.com/openai/codex/blob/main/codex-rs/protocol/src/protocol.rs), [Claude Code status-line rate limits](https://code.claude.com/docs/en/statusline#rate-limit-usage). Local token parsing continues to use the pinned MIT-licensed [Tokscale](https://github.com/junhoyeo/tokscale) core.

Release packages target macOS 11+ for Intel and Apple Silicon. Apple Silicon fan control remains experimental and capability-gated. Packages are ad-hoc signed and not notarized. Physical-device validation on macOS 11/12 remains pending.

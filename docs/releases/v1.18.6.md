# ShowMac 1.18.6 · build 273

- Link editing apps, games and other installed applications to saved fan scenes. App-based switching is opt-in, with one scene per application and persistent rules.
- Prefer a matching foreground app. Unrelated foreground apps keep the currently matched workload while it remains running; when all linked apps quit, restore the mode selected before automation was enabled.
- Pause app rules after a manual mode or curve choice, timed-session expiry, rejected authorization or an external controller conflict. Do not reset an unchanged scene or repeatedly retry failed control. Changing the duration keeps app switching enabled.
- Simplify the menu bar control card to one mode selector covering presets and scenes, a duration selector, an app-switching toggle and a settings shortcut. Remove competing selection rows and the duplicate fan-speed meter.
- Redesign Scenes & apps with readable scene rows, application icons, explicit Use actions and compact rename/delete menus. Associate running apps directly or select installed .app bundles; no Accessibility permission or window-content access.
- Preserve existing scenes, CPU/GPU curves, continuous control, launch/wake restoration, thermal overrides and hardware recovery behavior.

Release packages target macOS 11+ for Intel and Apple Silicon. Apple Silicon fan control remains experimental and capability-gated. Packages are ad-hoc signed and not notarized. Physical-device validation on macOS 11/12 and a long-duration hardware soak remain pending.

# ShowMac 1.18.0 · build 266

ThermalScope is now **ShowMac**. The app name, menus, widgets, exports and download packages use the new name. Existing preferences, history paths and widget links remain compatible.

- Native macOS 11+ desktop preview, with separate Intel and Apple Silicon packages.
- Keeps the existing purple interface and cross-version window layout.
- The Mac App Store monitoring edition is being prepared separately; this release remains the full desktop developer preview.

These packages use ad-hoc signing and are not notarized. Apple Silicon hardware control remains experimental and capability gated. See the architecture-specific installation instructions and SHA-256 checksums attached to this release.

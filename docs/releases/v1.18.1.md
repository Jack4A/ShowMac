# showmac 1.18.1

The app's public name is now consistently **showmac**, including its window title, menu, widget, application bundle and download archives. The existing bundle identifier, preferences, sensor access and full desktop controls are retained.

- Full desktop app for macOS 11 or later, with separate Apple Silicon and Intel downloads.
- Menu bar components, configurable popover cards, sensor history and fan control remain available.
- Packaging verification accepts the lowercase product name and continues to validate legacy releases.

This is an ad-hoc signed developer preview and is not notarized.

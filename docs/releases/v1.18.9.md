# ShowMac 1.18.9 · build 276

- Keep fan control running continuously by default. Replace the saved duration dropdown in the menu bar, thermal controls and scene manager with a compact Set timer… button.
- Offer one-shot 15/30/60/120-minute shortcuts and custom 1–1440-minute input. Show the active countdown on the button; cancel the timer to continue the same curve without an expiry.
- Preserve the original deadline across scene and application switches. When the timer ends, return fans to macOS and pause app-based rules; monitoring stays running.
- Count sleep towards the timer and prevent a backward clock change from extending it. If it expires during sleep, waking does not resume the old controlled scene.
- Do not save timers as the default for future sessions. Existing saved durations migrate to continuous while scenes, curves, app rules and launch preferences remain intact.
- Validate timer bounds, cancellation, expiry, app-switch continuity, wake behavior and preference isolation with simulated controls; render light/dark timer UI previews.

Release packages target macOS 11+ for Intel and Apple Silicon. Apple Silicon fan control remains experimental and capability-gated. Packages are ad-hoc signed and not notarized. Physical-device validation on macOS 11/12 and a long-duration hardware soak remain pending.

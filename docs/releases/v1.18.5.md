# ShowMac 1.18.5 · build 272

- Keep fan control running until stopped or the app quits, instead of forcing every mode to expire after 30 minutes. Optional 30-minute, 1-hour and 2-hour timers remain available.
- Save and switch named fan scenes, including editable Video editing, Gaming, Office, Media and Coding templates. Each retains its curve, CPU/GPU source and maximum-speed point. Scenes do not change Turbo Boost or system power settings.
- Share scene selection and duration between the main window and menu bar popover. Create scenes from the displayed curve; rename or delete them in one compact manager. Editing the active scene updates its saved curve. Deleting it returns fans to Auto.
- Remember the last confirmed choice and restore it after relaunch or wake by default. Auto is remembered too; restoration can be disabled. macOS authorization is still required, and unavailable sensors or another fan controller prevent an unconfirmed takeover.
- Preserve high-temperature full-speed overrides, sensor-loss recovery, conflicting-controller detection and helper-owner lifetime checks. Quitting or a failed connection returns fan control to macOS; the helper does not remain as an unattended background controller.
- Add bounded, keyboard-accessible scrolling for longer scene menus and keep the existing light/dark selector palette.

Release packages target macOS 11+ for Intel and Apple Silicon. Apple Silicon fan control remains experimental and capability-gated; Intel Turbo actions remain available independently. Packages are ad-hoc signed and not notarized. Physical-device validation on macOS 11/12 and a long-duration hardware soak remain pending.

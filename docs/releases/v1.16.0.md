## Apple Silicon arm64 补充包 / ARM64 add-on

新增 **`ThermalScope-1.16.0-macOS-arm64.zip`**，最低 macOS 13，主程序、辅助程序和小组件均为原生 arm64。

**这是实验性监测版，由 Intel Mac 交叉编译，尚未做 Apple Silicon 真机启动、功能或性能验证。风扇、睿频和电源设置控制已禁用。温度、风扇等读数依赖机型接口，可能不可用。** 当前为 ad-hoc 签名，未经公证。

附件：`INSTALL-arm64.txt`、`release-manifest-arm64.json`、`SHA256SUMS-arm64.txt`，与 ARM ZIP 一起下载后运行 `shasum -a 256 -c SHA256SUMS-arm64.txt`。已校验三部分的 arm64 架构、代码签名、ZIP 解压后完整性和动态库依赖；运行时检查明确标为未执行。

ARM 对应源码：[v1.16.0-arm64](https://github.com/Jackkakaya/ShowMac/tree/v1.16.0-arm64)，确切提交见 ARM 清单。Intel 的原发布标签和四个附件保持原样。仓库保持 **Private**。

### English

Added **`ThermalScope-1.16.0-macOS-arm64.zip`**, targeting macOS 13+, with native arm64 host, helper and widget executables.

**This is an experimental monitoring-only build, cross-compiled on Intel. It has not been launched or functionally/performance-tested on Apple Silicon hardware. Fan, Turbo and power-setting control are disabled. Temperature and fan readings depend on model-specific interfaces and may be unavailable.** Ad-hoc signed, not notarized.

Download `INSTALL-arm64.txt`, `release-manifest-arm64.json` and `SHA256SUMS-arm64.txt` with the ARM ZIP, then run `shasum -a 256 -c SHA256SUMS-arm64.txt`. Architecture, signatures, archive extraction and dynamic dependencies are checked; runtime checks are explicitly unexecuted.

ARM source: [v1.16.0-arm64](https://github.com/Jackkakaya/ShowMac/tree/v1.16.0-arm64), with the exact commit in its manifest. The original Intel tag and four assets are unchanged. The repository remains **Private**.

## 温控台 v1.16.0 · Intel macOS

首个 GitHub 预编译发布包，版本 **1.16.0 / build 260**。仓库及 Release 保持 **Private**；下载需要已获仓库访问权限的 GitHub 账号。

### 下载与安装

- 下载 **`ThermalScope-1.16.0-macOS-x86_64.zip`**，解压，将 `ThermalScope.app` 拖入“应用程序”后打开；无需安装 Xcode、Swift 或 Python。
- 适用 **Intel Mac（x86_64），macOS 13+**。当前验证机型为 MacBookPro16,1；另提供下方注明的 Apple Silicon ARM 实验包。
- 本包使用 **ad-hoc 签名，未经 Apple 公证**。macOS 可能提示无法验证开发者，Developer ID 签名与公证仍待完成。
- 顶部状态栏左键打开曲线面板，Dock 图标打开完整控制台；关闭主窗口后隐藏 Dock 并继续监测。
- 在“设置 → 语言”选择简体中文或 English。睿频控制依赖本机已有且获系统批准的 DisableTurboBoost 扩展，该驱动不随安装包提供。

### 内容与验证

应用包包含主程序、控制辅助程序与 WidgetKit 扩展。包含状态栏图表、温控曲线、性能诊断、图标与 Dock 行为更新，以及时间轴倒退、乱序输入和高频样本数量上限的修复。

提供双语 `INSTALL.txt`、记录源码提交的 `release-manifest.json` 和 `SHA256SUMS.txt`。将全部四个附件放到同一目录后运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

已验证 release 构建、深度签名校验、ZIP 解压后的签名与可执行权限、隐藏视图更新、本地化及已有领域/工具检查。实际 UI 帧卡顿、睡眠恢复、跨机型硬件控制和 30 分钟长测仍需专项验证。

## ThermalScope v1.16.0 · Intel macOS

First prebuilt GitHub release, **version 1.16.0 / build 260**. The repository and release remain **Private**; downloading requires a GitHub account with repository access.

### Download and install

- Download **`ThermalScope-1.16.0-macOS-x86_64.zip`**, extract it, drag `ThermalScope.app` into Applications and launch it. Xcode, Swift and Python are not required for the prebuilt app.
- Targets **Intel Macs (x86_64), macOS 13+**. Validated machine: MacBookPro16,1. A separate experimental Apple Silicon package is listed below.
- This package is **ad-hoc signed and not notarized by Apple**. macOS may report that the developer cannot be verified. Developer ID signing and notarization remain pending.
- Left-click the menu bar item for graphs. Click the Dock icon for the full console. Closing the window hides the Dock icon while monitoring continues.
- Choose English or Simplified Chinese in Settings → Language. Turbo Boost control depends on an existing macOS-approved DisableTurboBoost extension, which is not bundled.

### Contents and verification

Includes the host app, control helper and WidgetKit extension; menu bar charts, fan curves, diagnostics, icon and Dock updates; and fixes for rewinding history, out-of-order timeline inputs and unbounded high-frequency sample retention.

Assets include bilingual `INSTALL.txt`, a `release-manifest.json` identifying the source commit, and `SHA256SUMS.txt`. Download all four assets into one directory and run:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Validation covers release builds, deep signature verification, extracted-archive signatures and executable permissions, hidden-view updates, localization and existing domain/tool checks. Real UI hitches, sleep/wake, cross-machine hardware control and 30-minute soak coverage still need separate validation.

# ShowMac 1.18.23 · build 290

- Add an opt-in **Closed-lid mode** in Settings and a laptop button in the menu bar popover. Eligible MacBooks on external power can keep background tasks running with the lid closed, without requiring an external display.
- Show the verified system state. Battery/unknown power, desktop Macs, unreadable sleep state, critical thermal pressure and another sleep override block activation. macOS administrator authorization is required.
- Unplugging, switching off, quitting or critical thermal pressure releases the override. The mode starts off on every launch. Fan control remains independent; display sleep timers are unchanged.
- Use an independent privileged watchdog to restore sleep when the app or main control helper exits. Prepare a root-owned boot recovery job before changing `pmset disablesleep`; remove its fixed recovery files after verified restoration. If both processes are forcibly killed, recovery runs on the next boot.

System sleep, including manual sleep, is blocked while enabled. Keep ventilation clear and switch off before putting a MacBook in a bag. Do not run competing sleep-control utilities at the same time. Physical MacBook closed-lid validation is pending; local validation uses a desktop Mac, injected power/control fixtures, and localized light/dark UI captures.

All Token statistics, Agent/model filters and units, account allowance, menu bar customization, fan curves and scenes are retained. Release packages target macOS 11+ on Intel and Apple Silicon; individual device capabilities vary. Packages are ad-hoc signed and not notarized.

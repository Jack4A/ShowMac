# ShowMac 1.18.28 (295) — development preview

**Not a public binary release.** Current public downloads remain [1.18.23](https://github.com/Jack4A/ShowMac/releases/tag/v1.18.23). This page describes source/local-build changes since that release. No release tag has been published for 1.18.24–1.18.28.

- **Settings:** General, Menu bar and Features use compact, aligned rows. Only one menu bar editor opens at a time. About, developer, GitHub and update checks stay at the bottom. Widget preview opens directly; secondary help appears on hover.
- **Login startup:** start quietly in the menu bar after signing in. macOS approval status is read from the system. New systems use SMAppService; macOS 11–12 use a user login agent.
- **Closed-lid mode:** one switch, with external-power automation as the default. Battery waits for power; unplugging stops. The More menu includes temporary session-only operation. Authorization rejection pauses retries. Existing independent watchdog and boot recovery remain in place; real MacBook lid/power testing is still pending.
- **Intel Turbo Boost:** a confirmed-state switch in Settings → Features, retaining menu bar actions. Unknown/unsupported states cannot be toggled. Disabling still requires an existing, macOS-approved extension; Apple Silicon hides this setting.
- **Menu bar popover:** one status header, fan mode and optional controls in two rows, card editing in the footer, and exact sampling time on hover. Optional token allowance, CPU processes, warnings and hold-to-drag card configuration remain available. Panel height follows the visible sections.
- **Documentation and website:** refreshed English/Chinese light/dark sample screenshots, current settings instructions, electricity/Token guides and explicit separation of the development preview from verified public downloads.

Local SDK 27 builds declare macOS 12; official SDK 26.5 packages continue to target macOS 11. This development build is ad-hoc signed, not notarized. Current-host fixture rendering is not certification of every macOS or hardware model.

## 中文

**开发预览，尚未发布安装包。** 公开下载仍为 1.18.23；1.18.24–1.18.28 为源码与本机构建迭代，没有对应公开发布标签。

- 设置精简为通用、状态栏、功能，关于与更新置底；状态栏一次展开一个编辑区，小组件直接预览。
- 支持登录时在状态栏静默启动，并如实显示 macOS 批准状态。
- 合盖运行用一个开关，默认接电运行、拔电停止；其他方式收进更多菜单，保留异常退出与开机恢复保护。真实 MacBook 合盖／插拔电验证仍待完成。
- Intel 睿频进入设置，保留原菜单入口。只展示已确认状态，不绕过扩展安装与系统批准要求；Apple Silicon 隐藏。
- 状态栏弹窗简化顶栏与风扇区，底部编辑卡片，悬停查看采样时间；保留卡片拖动、余量、进程、告警和各项自定义。
- README 与官网同步近期功能和中英文浅深色示例截图，区分开发预览与公开下载。

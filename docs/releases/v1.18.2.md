# ShowMac 1.18.2 · build 269

ShowMac is now free and open source under the MIT license. The full desktop app includes menu bar customization, live sensor cards, history, diagnostics and supported fan controls without purchase or activation.

- Use **ShowMac** consistently in app titles, menus and widgets.
- Remove the redundant brand heading from the menu bar panel; use **Open main window** for its footer action.
- Replace the website purchase flow with free downloads, GitHub source and Star links. Old checkout URLs redirect to the open-source section.
- Keep the existing application identity and preferences, plus the verified automatic fan handoff and clearer system-control guidance from 1.18.1.

Separate Intel and Apple Silicon packages target macOS 11+. Hardware capabilities vary by Mac. Apple Silicon fan control remains experimental. Builds are ad-hoc signed and not notarized; see the installation guides for macOS security prompts.

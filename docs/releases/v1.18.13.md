# ShowMac 1.18.13 · build 280

- Add a dedicated Usage statistics sidebar page combining electricity and local AI token history under one Day/Week/Month/Year range. Keep a small electricity/token summary card on Live metrics.
- Read Codex and Claude Code JSONL session logs locally, with per-tool filters, time buckets and model breakdowns. Normalize input/output/cache/reasoning categories without double counting subsets.
- Deduplicate explicit request identities, streaming message revisions, cumulative counter snapshots and identifiable inherited fork prefixes. Exclude ambiguous fork counters and show partial-coverage warnings.
- Scan on a utility queue every minute, reusing unchanged files and committed line offsets. Handle partial final lines, truncation, moves and invalid caches. Keep usage metadata in a private local cache; no transcript text, login credentials, AI-service requests or uploads.
- Allow pausing local token scanning and choosing custom log folders. Missing logs, unsupported tools, web chats and other devices are outside coverage. Local token totals are not quota balances or actual bills.
- Preserve existing electricity history, power curves and optional rates. Refresh bilingual documentation, light/dark previews and website downloads.

Implementation research: [ccusage](https://github.com/ccusage/ccusage) and [CodexBar](https://github.com/steipete/CodexBar). ShowMac uses its own native Swift parser and incremental cache, without bundling either app or requiring Node/Python at runtime.

Release packages target macOS 11+ for Intel and Apple Silicon. Apple Silicon fan control remains experimental and capability-gated. Packages are ad-hoc signed and not notarized. Physical-device validation on macOS 11/12 remains pending.

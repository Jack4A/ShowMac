# ThermalScope v1.17.4

Build 265 · Intel x86_64 + Apple Silicon arm64 · macOS 11+

## 简体中文

- 按用户最新截图保留 v1.17.3 恢复的通透灰紫侧栏、更亮的选中高光和无外围框线的布局。
- 将主内容区的背景、左上圆角和细边界延伸到窗口顶部，修正此前落在标题栏下方的偏移；正文仍保留正常顶部留白。
- 14 个浅深色跨系统场景增加内容区顶部实际颜色检查，避免两边虽然一致却共同出现错误偏移。

最低部署目标仍为 macOS 11.0。旧系统尚未逐版真机验证。原有字体、图表交互、菜单栏/卡片设置与调速逻辑保持。Apple Silicon 风扇控制保持实验性、按能力开放；安装包沿用 ad-hoc 签名，未公证。

## English

- Retains v1.17.3's softly translucent gray-plum sidebar, lighter selection and removal of the extra sidebar outline, matching the latest reference.
- Extends the content background, leading top corner and subtle boundary to the window's top edge, correcting the offset below the titlebar while preserving content insets.
- Adds measured content-top color validation to fourteen light/dark cross-version scenes, catching a shared incorrect titlebar offset as well as differences between systems.

The minimum deployment target remains macOS 11.0; older systems have not all received physical-device validation. Typography, chart interactions, saved menu/card settings and fan controls remain. Apple Silicon fan control remains experimental and capability-gated. Packages remain ad-hoc signed and not notarized.

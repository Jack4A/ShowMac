# ThermalScope v1.17.0 · 温控台

Build 261 · Intel x86_64 + Apple Silicon arm64 · macOS 13+

## 简体中文

- 重整原生侧栏、性能诊断和设置页，统一深浅主题、字体、边距与卡片层次，移除和侧栏重复的大标题。
- 状态栏图标、数值和真实趋势可自由组合；支持全部可读传感器、组件独立图标和颜色，默认黑白，内外边距可设为零。
- 菜单栏弹窗支持 1–8 张自定义指标卡片；弹窗和设置共用添加、排序、删除配置，风扇控制和 CPU 排行可独立显示。
- 常用传感器展示可读名称、用途说明及近期趋势，完整探头包含温度、转速、功率、电压和电流。缺失值保持缺失，曲线保留真实采样与中断，并显示既有阈值的告警颜色。
- 风扇控制简化为五档和一张可拖动曲线。Apple Silicon 提供实验性独立风扇控制，按能力开放，首次需要管理员授权，控制最长 30 分钟；Intel 睿频及电源写入在 ARM 上继续禁用。
- 新增 GitHub Actions 自动检查、双架构构建附件，以及版本标签触发的校验与发版流程。

Intel 下载 `ThermalScope-1.17.0-macOS-x86_64.zip`；Apple Silicon 下载 `ThermalScope-1.17.0-macOS-arm64.zip`。解压后将 `ThermalScope.app` 放入“应用程序”。每个架构另附安装说明、构建清单与 SHA-256 校验值。

当前安装包仍为 **ad-hoc 签名，未经过 Apple 公证**。macOS 可能提示无法验证开发者。Apple Silicon 控制为实验性功能，机型验证范围见 [硬件说明](https://github.com/jackinprod/ShowMac/blob/v1.17.0/docs/APPLE_SILICON_FANS.txt)。CI 的虚拟机检查不等同于真实硬件或所有旧系统验证。

新增文案已提供中英文；部分日语、韩语、德语、法语和西班牙语条目暂按应用既有逻辑回退英文。

## English

- Refined native navigation, diagnostics and settings, coordinated light/dark surfaces and typography, and removed headings that repeated sidebar destinations.
- Compose menu-bar icons, values and real trends from every readable sensor, with per-component icons/colors, black/white defaults and independently adjustable padding.
- Configure 1–8 compact popover cards from either the popover or Settings. Add, reorder and remove entries with shared persistence; fan controls and top CPU processes are optional.
- Human-readable common sensors include recent trends. The complete inventory exposes temperature, RPM, power, voltage and current. Missing values and gaps remain explicit; existing thresholds color warning segments.
- Fan control uses five presets and an editable curve. Experimental Apple Silicon fan control is capability-gated, requires administrator authorization and returns to automatic after at most 30 minutes. Intel Turbo and power-setting writes remain disabled on ARM.
- Added GitHub Actions checks, dual-architecture build artifacts and verified tag-driven releases.

Download `ThermalScope-1.17.0-macOS-x86_64.zip` for Intel or `ThermalScope-1.17.0-macOS-arm64.zip` for Apple Silicon. Extract and move `ThermalScope.app` to Applications. Each architecture includes installation notes, a source/build manifest and SHA-256 checksums.

Packages are **ad-hoc signed and not notarized**. macOS may report that the developer cannot be verified. Apple Silicon fan controls remain experimental; see [hardware validation scope](https://github.com/jackinprod/ShowMac/blob/v1.17.0/docs/APPLE_SILICON_FANS.txt). CI virtual-machine checks do not establish support for every physical device or older macOS release.

New strings have Chinese and English coverage. Some Japanese, Korean, German, French and Spanish entries currently use the application’s existing English fallback.

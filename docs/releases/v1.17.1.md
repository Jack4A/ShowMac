# ThermalScope v1.17.1

Build 262 · Intel x86_64 + Apple Silicon arm64 · macOS 11+

## 简体中文

- 将主应用、辅助程序和小组件的最低系统要求统一降为 macOS 11.0。
- macOS 11/12 保留实时趋势、真实采样查询、警告色、风扇选档与拖动曲线；新系统继续使用 Swift Charts 和可用的原生玻璃效果。
- 侧栏、设置、确认弹窗、等宽数字和图标增加旧系统兼容路径。macOS 11 不显示系统低电量模式选项，也不产生该功能的建议。
- CI 固定 Xcode 26.6 / macOS 26.5 SDK；Xcode 27 的部署下限已为 macOS 12，不能用于生成 macOS 11 安装包。
- 所需 Swift 并发运行库随包签名，移除构建机工具链路径；CI 检查三套可执行文件的实际最低版本、新框架弱链接及运行库完整性，并渲染 14 个兼容界面。

macOS 11/12 已完成 API 编译与部署/归档检查，兼容界面在当前 runner 上渲染检查；尚未在这两个旧系统上进行真机启动、风扇控制、睡眠唤醒或长时间运行实测。Apple Silicon 风扇控制仍为实验性、按硬件能力开放；Intel 包为交叉编译，其静态验证不代表目标架构运行时验证。小组件支持 macOS 11+ 通知中心，桌面需要 macOS 14+。

安装包沿用 **ad-hoc 签名，未经 Apple 公证**。硬件范围见 [Apple Silicon 风扇说明](https://github.com/Jackkakaya/ShowMac/blob/main/docs/APPLE_SILICON_FANS.txt)。部分新增文案在非中文语种下仍明确回退英文。

## English

- App, helper and widget now target macOS 11.0.
- Compatible real-sample charts preserve history inspection, warning colors, fan presets and draggable curves on macOS 11/12. Newer systems retain Swift Charts and available native glass effects.
- Navigation, settings, confirmations, numeric typography and symbols have older-system paths. Low Power Mode options and recommendations are omitted on Big Sur.
- CI pins Xcode 26.6 / macOS 26.5 SDK, bundles and signs back-deployed Swift concurrency runtimes, removes development-toolchain search paths and verifies actual deployment commands for all executables, weak frameworks and runtime completeness. Fourteen light/dark layouts exercise the compatibility paths.

API compilation, deployment/archive inspection and current-runner compatibility rendering are checked. Physical-device launch, controls, sleep/resume and long-running validation on macOS 11/12 remain pending. Apple Silicon fan control remains experimental and capability-gated; Intel runtime execution is not validated by cross-compilation. Notification Center widgets require macOS 11; desktop widgets require macOS 14.

Packages remain **ad-hoc signed and not notarized**. Some newer strings in other languages explicitly fall back to English.

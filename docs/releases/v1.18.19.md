# ShowMac 1.18.19 · build 286

- Identify Codex and Claude with provider glyphs on allowance cards, default menu bar allowance components and the popover summary. Custom menu icons/colors remain independent; the default menu bar stays monochrome. Provider identity is not a personal account avatar.
- Group allowance windows by tool/pool, with one provider heading, readable remaining percentages, reset times and the last-report age. Keep a single available window compact. Preserve separate shared/model pools and the existing freshness rules.
- Add native press-and-hold dragging to popover metric cards: drop onto a card to reorder, or onto the removal zone at the bottom to remove. Hovering, Escape and invalid/outside drops do not alter saved cards. Keep at least one metric card. Clicking still opens details.
- The Token summary can also be dragged to remove. Settings → Popover cards can independently show it again, without removing menu bar components. Older saved card layouts remain compatible.
- Retain separate Electricity / Token tabs, all 60 local history sources, optional Claude Code sync and Chinese magnitude units (万 / 百万 / 千万 / 亿 / 万亿); English keeps K/M/B.
- Add explicit manual CI publication after the existing native, cross-version and dual-architecture release gates, avoiding a second tag build and making main-branch engine caches reusable.

Provider glyphs derive from [CodexBar](https://github.com/steipete/CodexBar), pinned at `20ada8abf0e4e2267aaa8c7cc9cf891cdf866838`, under its MIT license. Original SVGs, PDF derivatives and the license are bundled under Resources/ProviderIcons. No provider authentication or identity-reading capability is added.

Release packages target macOS 11+ for Intel and Apple Silicon. Apple Silicon fan control remains experimental and capability-gated. Packages are ad-hoc signed and not notarized. Physical macOS 11/12 device validation remains pending.

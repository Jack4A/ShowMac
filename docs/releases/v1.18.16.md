# ShowMac 1.18.16 · build 283

- Expand local token support from two tools to the complete 60-client Tokscale catalog, including Cursor, Gemini, OpenCode, Cline, Roo Code, Kiro, Zed, Trae and GitHub Copilot.
- Directly bundle the pinned MIT-licensed Tokscale core and reuse its source discovery, parsers and deduplication. No extra runtime installation or API keys are needed.
- Keep electricity and tokens together in Usage statistics and retain the compact homepage card. Search sources; show detected tools first and expand the complete catalog when needed.
- Read local logs, databases, exports and already-synced usage caches. Clearly disclose missing data, Cursor's cache requirement and upstream token estimates. These counts are not account quota or actual invoices.
- Run the native parser in offline mode. Cache only usage metadata and hashed identities, reuse unchanged data and preserve the last successful snapshot if scanning fails. Do not modify logs or electricity history.
- Update bilingual documentation, website downloads and token previews. Include upstream, nested Apache-2.0 decoder and dependency license notices in the app.

Engine: [Tokscale](https://github.com/junhoyeo/tokscale), MIT, commit `82613d2f5e96654ce3729892afbb0025979f1c75`. [Coverage and implementation](../TOKEN_USAGE.md).
